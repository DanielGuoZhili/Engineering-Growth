# Transferable engineering skills

## North-star outcome
Be interview-ready for solid software engineering roles in Japan-based global tech companies, not just three named employers. No guaranteed offer or date.

## Core competencies and proof
| Area | Evidence to accumulate | Priority |
|---|---|---|
| Independent JavaScript/TypeScript | Solve, test, debug, and explain unseen tasks without AI | P0 |
| Data structures / algorithms | Explain trade-offs, edge cases, complexity; timed practice | P0 |
| React / web engineering | Independently build accessible features, APIs, state and tests | P0 |
| Testing, debugging, Git | Reproducible bug reports, unit/integration tests, readable commits | P1 |
| API / SQL / backend | Build, secure, and deploy a small service | P1 |
| System design | Diagram, trade-offs, requirements, failure modes | P1 |
| English technical communication | Clear project explanation and mock interviews | P1 |
| AI applications | Only after a strong engineering baseline; deploy and evaluate | P2 |

## Weekly allocation (suggested, adjust to reality)
60% hands-on engineering and algorithms, 20% test/debug/refactor, 10% explaining work, 10% recruiting-market review.

## Review rule
Review the latest official job descriptions for Google Japan, Microsoft Japan, Amazon Japan and relevant peers. Record source URLs, checked dates, required skills and meaningful changes; do not rebuild the plan for minor wording edits.
