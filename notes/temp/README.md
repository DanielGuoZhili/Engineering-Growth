# 临时笔记区

这里存放尚未整理的原稿。一个想法可以一个文件，也可以把同一天的碎片写在一起；推荐使用 `.md` 扩展名，以便获得 VS Code 的 Markdown 预览和链接能力。

## 推荐命名

```text
YYYY-MM-DD-short-topic.md
```

例如：`2026-11-01-two-sum.md`。不确定主题时可以写 `2026-11-01-misc.md`。

## 使用方式

1. 复制 [`_template.md`](_template.md)，或直接新建任意文本文件。
2. 自由记录，不需要先整理语法和结构。
3. 要求 Agent 回答的地方写 `@Saber：你的问题`。
4. 告诉 Saber 要整理的文件名；整理结果会进入[当前主笔记](../主笔记-1.md)。

临时稿在整理后仍然保留，处理状态记录在[全局索引](../INDEX.md)中。不要在这里放密码、密钥、公司机密或客户代码。
